## Diferencia entre JAVA Y JAVAC
JAVA ->  Es el lenguaje de programacion que nos permite comunicarnos con el software.
Actualmente es usada es para mantener las  aplicaciones creadas desde sus inicios con java  o para bancos.
JAVAC -> Compila todos los archivos de clases e interfaces escritas en java y lo convierte en archivo bytecode

## Git y GitHub

Git:Nos permite llevar un control de versiones de un proyecto.
GitHub:Nos permite alojar imagenes documentos proyectos desarrollados en algun lenguaje de programacion remotamente.

## Repositorio
Es un tipo de almacenamiento digital el cual los desarrolladores utilizan para realizar y administrar cambios en el codigo fuente de una aplicacion o software.

## API 
Es un mecanismo que permiten a dos componentes o sistemas de softaware comunicarse
entre si mediante un conjunto de reglas establecidas y protocolos de seguridad.

## METODO HTTP GET -> Es un metodo para trabajar con APIs 
Es una peticion realizada por un cliente su objetivo es recuperar datos sin modificar nada en el servidor.
Esta peticion se realiza mediante un URL(Direccion Web Unica) especifica

## ¿Que problema resuelve Spring Boot?
Elimina la complejidad de la configuracion manual dentro del ecosistema, permitiendo desarrollar aplicaciones sitio web o microservicios mas rapido y sencillo.

## ¿Qué es un endpoint?
Es la ruta o URL especifica para realizar una peticion y obtener una repuesta.
## ¿Qué hace un Controller?
Es un componente de software que permite gestionar y configurar el flujo de datos entre dos partes.
## ¿Qué diferencia existe entre JAVA y SpringBoot? 
Java es un lenguaje de programacion orientada a objetos el cual tiene su sintaxis definida.
Spring Boot es un framework(Conjunto de librerias) para crear APIS RESTful de forma rapida,servicios en la nube  o microservicios.

## ¿Qué es JSON?
Es un formatode texto  ligero  para el intercambio de datos.
Facil de leer y escribir por su coleccion clave/valor.

## ¿Qué significa serializar?
Es el proceso de convertir un objeto en la memoria en un formato plano y secuencial como (texto,JSON,XML o bytes).

## ¿Qué significa GET?
Solicita y lee datos de un servidor en formato JSON.

## ¿Qué es un commit?
Es un captura de cambios realizados a un archivo o la creacion de uno nuevo

## ¿Qué hace git push?
Sube todos lo cambios guardados en tu computadorea hacia el servidor remoto conectado

## ¿Qué significa origin?
Es el nombre por defecto que se le da al repositorio remoto

## ¿Qué significa main?
Es la version estable del proyecto.
